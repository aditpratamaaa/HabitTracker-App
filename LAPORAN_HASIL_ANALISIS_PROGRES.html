2. Arsitektur & Fungsionalitas yang Telah Selesai

🔒 A. Modul Keamanan & Autentikasi (Sprint 02)

  • Hardware Keystore / Keychain: Penyimpanan token sesi aman memanfaatkan hardware cryptographic module via expo-secure-store.
  • Protected Route Guard: Pengalihan navigasi otomatis di src/app/_layout.tsx. Pengguna tanpa token akan dikunci di /login, dan pengguna ber-token langsung menuju beranda /.
  • Fitur Uji Akun Cepat: Form login dilengkapi tombol auto-fill untuk akun demo (user@mail.com / password123).

📋 B. Manajemen Kebiasaan & Gamifikasi (Sprint 01)

  • Operasi CRUD Lengkap: Pengguna dapat menambah, mencentang selesai/batal, serta menghapus kebiasaan dengan konfirmasi dialog.
  • Penyimpanan Persisten: Data tersimpan permanen di perangkat menggunakan AsyncStorage.
  • Mesin Runtutan (Streak Engine): Perhitungan api konsistensi harian (🔥) yang pintar menjaga streak jika hari ini belum dicentang tetapi kemarin sudah tuntas.
  • Auto-Reset Tengah Malam: Deteksi pergantian hari otomatis via timer 00:00 dan listener AppState.

🎨 C. Pembaruan Desain TaskFlow Modern Soft-UI

  • Kartu Progres Harian: Kartu besar solid Indigo (#4F46E5) dengan persentase progres tebal dan drop shadow lembut.
  • Kartu Kebiasaan 20px: Sudut membulat 20px, tanpa border keras, dan tombol centang lingkaran sempurna 44x44px.
  • Umpan Balik Taktil (Haptics): Memberikan getaran motor nyata pada ponsel saat pengguna berhasil mencentang target kebiasaan.
  • Bottom Sheet Modal: Formulir tambah kebiasaan dengan pemilih emoji visual beragam.

3. Cara Menjalankan Aplikasi

Aplikasi dapat dieksekusi secara praktis dari root workspace:

# Menjalankan Dev Server
npm start

# Menjalankan langsung di Web Browser
npm run web

# Menjalankan di Android Emulator / Device USB
npm run android

4. Rekomendasi Tahap Lanjutan (Opsional)

  1. Notifikasi Lokal (expo-notifications): Pengingat otomatis di jam malam untuk mengevaluasi kebiasaan harian.
  2. Grafik Statistik & Heatmap: Tampilan kalender ala GitHub contribution graph untuk memantau kemajuan bulanan.
  3. Sinkronisasi Cloud: Menghubungkan penyimpanan lokal dengan database cloud (Firebase / Supabase).
